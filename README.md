# CampusConnect

CampusConnect is a full-stack student social networking web application built using **ASP.NET Core MVC** and **Microsoft SQL Server**. The platform is designed to help students connect with classmates, share posts, manage profiles, receive notifications, and interact within a campus-based digital community.

## Project Overview

CampusConnect focuses on improving communication and engagement inside a college or university environment. It provides a centralized platform where students can connect with each other, search for friends, share updates, and stay informed about campus activities.

The project follows the MVC architecture pattern and uses SQL Server as the database for storing application data.

## Key Features

- User registration and login
- Student profile management
- Post creation and sharing
- Search functionality for posts and users
- Notification system
- Profile dropdown and account options
- Responsive navigation bar
- Clean and modern user interface
- SQL Server database integration
- MVC-based application structure
- Server-side rendering using Razor Views

## Architecture

CampusConnect follows the **Model-View-Controller MVC** architecture.

- **Models** handle application data and business entities.
- **Views** handle the user interface using Razor syntax.
- **Controllers** handle user requests, application logic, and communication between Models and Views.
- **SQL Server** stores user data, posts, notifications, and other application records.
